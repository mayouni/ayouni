# cover.png — drop your file here

The HTML reader (`index.html`) references `cover.png` in this directory.

To complete the reader: copy your giraffe cover artwork (or whatever cover you are currently using) to:

```
web/cover.png
```

Once the file is in place, the reader will display it in the hero area of the overview view. Until then, the browser shows a broken-image placeholder.

After dropping the file, you can delete this `COVER_PLACEHOLDER.md` — it serves no purpose beyond reminding you the file is missing.
